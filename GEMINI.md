# GEMINI.md

## Directory Overview

This directory contains the project documentation and specifications for a vacation and remote work approval system. The system is designed to be a simple and fast web-based application for a company's internal network, where external internet access is not available.

## Key Files

*   **`vacation-system summary.txt`**: This file contains the detailed specifications for the vacation and remote work approval system. It outlines the project's requirements, including:
    *   System features and functionalities.
    *   User roles and hierarchies.
    *   Leave types and application procedures.
    *   Rules for calculating and managing leave quotas.
    *   Screen layouts and UI descriptions for different user views (login, main dashboard, application form, approval queue, admin panel).

## Usage

The contents of this directory are intended to be used as a reference for the development of the vacation and remote work approval system. The `vacation-system summary.txt` file serves as the primary source of truth for the project's requirements and should be consulted by developers, designers, and project managers to ensure that the final product aligns with the specified functionalities and user experience.
