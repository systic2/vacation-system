앱보다는 웹 방식을 선호
간단하고 빠른 시스템을 위한 프로그래밍 언어, 프레임워크, DB 선택
반응형 디자인 적용

휴가 신청 절차
신청 양식 작성 - 파트장 결재 - 팀장 결재
파트장이 팀장인 경우 파트장 결재 생략함

연차일수기준
올해 입사자
- 월초 (~10일이내) 입사월 포함한 12월까지 월마다 1개 예) 4월 5일 입사 - 총 9개
- 월초 아닌 경우 입사월 제외한 12월까지 월마다 1개 예 4월 25일 입사 - 총 8개
작년 입사자부터
연차 기본 15개 지급
이후 2년마다 15개에서 1개씩 증가 예) 2025년 기준 2023년 입사자 연차 총 15개/2022년 입사자 연차 총 16개/2014년 입사자 연차 총 20개

연차사용기준
서버 시간은 대한민국 서울 기준
매년 1월 1일 초기화
연차 개수 초과 사용 불가
해당 날짜 이전 신청 불가
동일 날짜 신청 불가
경조휴가/병가/교육/출장/대체휴가/기타는 연차 개수 차감 안됨
재택근무는 한 달에 1번 사용 가능(연차 개수 차감 안됨)

화면 개요
로그인(기본)
-사번과 비밀번호로 로그인
메인화면
-스마트폰 알림과 유사한 알림 내역
-사용자 정보(이름, 팀, 부서, 직급, 직책)
-연차 정보(총 개수, 잔여 개수)
-신청 내역
-승인 대기 목록
신청화면
-휴가 종류
-휴가 사용 기간
-대체근무자(같은 파트 인원만 선택 가능)
-사유
결재화면
-팀장은 파트장 결재 완료된 승인 대기 목록
-파트장은 파트 내 인원들 휴가 신청 승인 대기 목록
-팀장이 파트장인 인원들 휴가 신청 승인은 파트장 결재 건너뛰고 팀장 승인 대기
관리자화면
-사용자 추가(사번은 추가할 때 입력)
-사용자 목록
-사용자 삭제
-사용자 비밀번호 초기화(초기화 비밀번호는 고정 'a123456!')
